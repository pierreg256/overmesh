The contract

One successful write means two durable replicas.

W = 2

A client success is returned only after both selected regions accept the write.

R = 2 metadata

Both signed heads are compared; blob bytes stream from one deterministic primary, with replica fallback only if it is unavailable.

Entra only

OAuth bearer tokens and Azure RBAC replace keys, connection strings, and every form of SAS.

The trade-off

Availability is bounded by the integrity claim.

Overmesh does not pretend a partial write is durable. It rejects success when either replica fails, keeps gateways stateless, and treats signed metadata and the Ring as verifiable inputs.
